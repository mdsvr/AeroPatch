How it will work for people

People choose how much to install. Each level works on its own, so someone who can't install Docker still gets real help.

LevelWhat they installWhat they get
CheckOne small install, about 2 minutes, no admin rightsUp to five problems, each explained: what could go wrong and when it matters
SuggestPlus the free AI model, about 3 GBA suggested fix for each problem; nothing of theirs is run
TestPlus Docker Desktop, the hardest installThe fix is also tried against the project's own tests in a sealed box with no internet

What the tool says about a fix

It never says "fixed" or "safe". It says what it checked, and later how often that label was right ("N of M times").

  • Scanner quiet, your tests still passThe warning is gone and the project's own tests still pass. An attack was not tried.
  • Scanner quiet, not testedThe warning is gone, but nothing was run: no Docker, or the project has no tests.
  • Not fixed, warning keptShown with the check that failed and what to do next.
  • Probably not a real problemFolded away, never deleted. One click shows it.
